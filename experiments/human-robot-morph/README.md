# 로봇화 비율 · 인간 → 로봇 부위 전환 데모 (+ 사진으로 꾸미기)

- 관련 이슈: #17
- 관련 실험: #11 웹캠 정지 이미지와 부위별 로봇 표현 (`experiments/webcam-robot/`, 부위 이름을 같이 씀)

## 검증할 질문

로봇화 비율(0–100%)에 따라 인간 모델의 부위를 로봇 부위로 하나씩 바꿀 수 있는가? 두 모델이 같은 뼈대를 쓰므로 같은 동작을 하면서 부위만 바꿀 수 있는지 확인한다.

참여자 사진 한 장으로 아바타의 머리 모양·피부색·머리색·옷 색을 비슷하게 맞출 수 있는가?

## 실행

저장소 루트에서 실행한다. 모델을 `assets/models/`에서 읽기 때문에 이 폴더가 아니라 루트에서 서버를 연다.

```sh
python3 -m http.server 8137
# 브라우저에서 http://localhost:8137/experiments/human-robot-morph/
```

three.js 0.180.0(앱과 같은 버전), Draco 압축 해제기, MediaPipe Tasks Vision 1.1.0(웹캠 실험과 같은 버전)을 jsDelivr CDN에서 받는다. 인식 모델 2개(selfie_multiclass, face_landmarker)는 Google 저장소에서 받으므로 인터넷 연결이 필요하다. 웹캠은 localhost에서만 열린다.

판정 규칙 테스트:

```sh
node --test avatar.test.js
```

## 사용법

### 사진으로 꾸미기

- **사진 올리기** 또는 **웹캠으로 찍기**(한 번 더 누르면 촬영)를 누르면 사진을 분석해 아바타에 바로 입힌다.
- **분석 영역 보기**: 머리카락(주황)·얼굴(파랑)·옷(보라)으로 인식한 영역을 사진 위에 표시한다.
- 결과가 마음에 들지 않으면 머리 모양 목록과 색 선택으로 직접 고칠 수 있다. **기본 모습**으로 되돌린다.
- 사진은 브라우저 메모리에서만 쓰고 저장하거나 서버로 보내지 않는다.

### 로봇화

- **로봇화 비율 슬라이더**: 비율이 부위 기준값 이상이면 그 부위가 로봇으로 바뀐다. 약 0.5초 동안 서서히 바뀌며 빛이 난다.
- **부위별 기준값**: 숫자를 바꾸면 바뀌는 순서와 시점을 바로 실험할 수 있다. 기본값은 오른팔 15 → 왼팔 30 → 오른다리 45 → 왼다리 60 → 몸통 75 → 머리 100이다. 머리는 자아를 상징하므로 마지막에 바뀐다.
- **질문 3개 시뮬레이션**: 회사가 원하는 답의 비율이 곧 로봇화 비율이다.
- **합격선**: 기획서 기준 75% 이상이면 합격으로 표시한다.
- **동작**: 로봇 애니메이션 18개를 두 모델에 함께 재생한다.

## 구조

### 사진 분석 (`avatar.js`)

1. MediaPipe `selfie_multiclass`로 사진을 머리카락·얼굴 피부·몸 피부·옷·배경으로 나눈다.
2. MediaPipe `face_landmarker`로 이마·턱·볼·눈썹 위치를 찾는다.
3. **색**: 영역별로 밝기 상·하위 15%를 뺀 평균색을 구한다. 피부·머리는 동숲풍 팔레트에서 가장 가까운 색으로, 옷은 너무 어둡거나 칙칙하지 않게 살짝 보정한다.
4. **머리 모양**: 얼굴 높이를 1로 두고 네 가지를 잰다. 기준값은 `HAIR_RULES`에 있다.

| 측정값 | 뜻 | 판정 |
| --- | --- | --- |
| 머리카락 양 | 얼굴 면적 대비 머리카락 면적 | 0.12 미만 → 아주 짧은 머리 |
| 턱 아래 길이 | 옆머리 끝이 턱보다 얼마나 아래인지 | 0.35 초과 → 긴 머리, -0.2 초과 → 단발 |
| 앞머리 | 이마 영역 중 머리카락 비율 | 0.35 초과 → 짧은 앞머리 |
| 정수리 두께 | 이마 위로 머리카락이 얼마나 있는지 | 0.12 미만 → 아주 짧은 머리, 그 밖 → 이마 보이는 머리 |

얼굴을 찾지 못하면 머리 모양은 바꾸지 않고 색만 바꾼다. 측정값은 화면에도 표시되므로 실제 사진으로 기준값을 조정할 수 있다.

### 로봇화

- 인간(`assets/models/human/human_male.glb`)과 로봇(`assets/models/robot/robot.glb`)을 같은 자리에 겹쳐 놓는다. 두 모델에 같은 애니메이션을 같은 시간으로 재생한다.
- 각 메시가 붙은 뼈 이름으로 부위를 나눈다(`BONE_PART`). 머리 / 몸통 / 왼팔·오른팔 / 왼다리·오른다리 6개다.
- 부위마다 인간 메시와 로봇 메시의 투명도를 교차시켜 바꾼다. 전환은 실제 경과 시간 기준이라 프레임이 떨어져도 끝까지 진행된다.
- 바꿀 값은 스크립트 위쪽 `PASS_LINE`, `PARTS`, `QUESTIONS`에 모여 있다.

## 한계 / 다음 결정

- 답이 두 개뿐인 질문 3개로는 비율이 0·33·67·100%만 나온다. 75% 합격선을 넘으려면 세 질문 모두 회사 답이어야 하므로 답변별 점수(가중치)를 정해야 한다.
- 머리 모양 판정 기준값은 가상 데이터로만 맞췄다. 실제 사진 여러 장으로 조정해야 한다.
- 조명이 어둡거나 색이 섞인 곳에서는 피부·머리색이 틀릴 수 있다. 전시장 조명을 고정하면 안정된다.
- 몸 체형·옷 종류·안경은 아직 반영하지 않는다.
- 앱(`app/`)의 `answer` 이벤트와 연결하는 작업은 후속이다.
