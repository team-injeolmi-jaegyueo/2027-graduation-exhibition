# experiments

통합 앱에 넣기 전 기술의 가능성과 한계를 검증합니다.

실험별로 `webcam-capture/`, `body-landmarks/`, `robot-compositing/`처럼 폴더를 만듭니다. 아직 실행하지 않은 실험 폴더를 미리 늘리지 않습니다.

각 실험 README에는 다음을 기록합니다.

1. 연결된 이슈, 검증할 질문과 성공 기준
2. 사용 장비·OS·런타임·라이브러리 버전
3. 설치 및 실행 방법
4. 사용한 테스트 자료와 출처
5. 결과, 실패 조건, 통합 여부와 다음 작업

초기 웹캠 실험은 정지 이미지 촬영부터 시작합니다. 인식 결과를 통합 앱에 넘기는 형식은 검증 후 docs에 기록합니다. 실제 관객 사진은 저장소에 넣지 않습니다.
